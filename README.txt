آموزش‌یار — نسخه اولیه نمایشی

فایل‌ها:
- index.html: صفحات معرفی، ورود آزمایشی، صفحه اصلی، رایگان، خرید و پنل مدیریت
- style.css: ظاهر فارسی و راست‌چین
- app.js: رفتار نمونه و ذخیره محلی روی همان دستگاه
- manifest.json و sw.js: پایه نصب‌پذیری PWA

محدودیت‌های مهم:
- این نسخه نمونه اولیه رابط کاربری است، نه سامانه آماده انتشار.
- ثبت‌نام و ورود واقعی، پایگاه داده و پنل امن مدیر هنوز پیاده‌سازی نشده‌اند.
- اطلاعات محلی فقط روی همان مرورگر/دستگاه می‌مانند.
- درگاه پرداخت متصل نیست و دکمه خرید صرفاً پیام نمایشی نشان می‌دهد.
- پیش از استفاده واقعی توسط دانش‌آموزان، باید میزبانی HTTPS، امنیت، حریم خصوصی و backend بررسی و پیاده‌سازی شود.
- راه‌اندازی پرداخت باید با رضایت و حساب قانونی والدین/سرپرست انجام شود.
برای آزمایش، index.html را در مرورگر باز کنید. برای نصب PWA باید فایل‌ها روی یک میزبان HTTPS قرار بگیرند.
